## فارسی

MaxWorld یک کلاینت دسکتاپ برای ویندوز است که روی هسته **Xray** ساخته شده.

- VLESS · VMess · Trojan · Shadowsocks · WireGuard · Hysteria2
- Reality / TLS · WebSocket · gRPC · HTTPUpgrade · XHTTP · KCP
- پروکسی سیستم و حالت TUN
- اشتراک، پینگ، سرعت زنده، حجم و انقضا
- مسیریابی هوشمند و سپر تبلیغات
- فارسی (راست‌به‌چپ) و انگلیسی، چند پوسته، سینی سیستم

## English

Desktop Xray client for Windows.

- VLESS, VMess, Trojan, Shadowsocks, WireGuard, Hysteria2
- System proxy and TUN
- Subscriptions, live ping and speed, data and expiry
- Smart routing and an ad shield
- Persian (RTL) and English

Both the installer and the portable build are attached to every [release](../../releases/latest).
